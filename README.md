# wayfarer

長輩輔助工具、老人家常用的軟體，方便協助安裝。

## CMD

``` flutter
刪除快取
flutter clean

更新相依性
flutter pub get

查詢裝置
flutter devices

指定測試
flutter run -d (ID)
輸出 Log
flutter logs -d (ID)


flutter run -d all
```

``` shell
編譯前測試
flutter run --release

編譯
flutter build apk --release
∟ build\app\outputs\flutter-apk\app-release.apk
```
